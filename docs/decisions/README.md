# docs/decisions · 决策记录（ADR-lite）

## 这个目录是什么
记录**影响长期协作/架构/规范**的决定，避免"规则变了但只在对话里"。

## 规则
- 文件名：`NNNN-<kebab-title>.md`（四位编号，递增，不复用）；
- 每篇固定结构：背景 → 决定 → 后果 → 规则/约束；
- 决策生效后，根 `AGENTS.md` / `ROADMAP.md` 必须引用对应编号；
- 被推翻的决策不删除，追加"已废止（被 NNNN 取代）"。

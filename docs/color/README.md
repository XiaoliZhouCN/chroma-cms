# docs/color · 学习手册

## 这个目录是什么
色彩管理理论学习手册：从文件字节到屏幕像素的 L0–L5 分层文章。

## 文件与职责
- `00-index.md`：文章总索引（编号/状态/实验/测试映射）；
- `<编号>-<标题>.md`：单篇文章（固定五段：概念 → 公式/数值 → 实验 → 断言 → 常见误解）。

## 规则
- 文章里的公式与代码必须与 `src/color` 实现一致；
- 每篇必须对应至少一个可运行实验与一组测试断言；
- 状态在 `00-index.md` 维护（计划/编写中/已发布）；
- 编号唯一、按层排列，不复用旧编号。

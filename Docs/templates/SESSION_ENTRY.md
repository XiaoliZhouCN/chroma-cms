# 会话记录模板

> 复制本文件的结构，**追加**到 [../SESSION_INDEX.md](../SESSION_INDEX.md)。
> 不要新建文件，不要改写已有条目。

## 索引行（加到表格末尾）

```
| NNN | YYYY-MM-DD | <一句话目标> | <产出，用分号分隔> | <未决 / 风险> | <下次第一件事> |
```

## 详细记录（加到"详细记录"末尾）

```
### NNN · YYYY-MM-DD · <标题>

**目标**：<本次要达成什么，一句话>

**决策**
- <本次做出的决定；涉及取舍的必须指向 ADR 编号>

**产出**
- <文件 / 功能 / 测试，具体到路径或命令>

**未决 / 风险**
1. <还没解决的事；能落到 ROADMAP 待决表的就落过去>

**踩坑**
- <遇到的问题与原因；同一个坑不要踩第二次>

**下次第一件事**：<下个会话打开仓库后第一件要做的事，具体到可执行>
```

## 写作要求

| 字段 | 要求 |
|---|---|
| 目标 | 动词开头，一句话，不写背景 |
| 产出 | 可验证（文件存在 / 命令能跑 / 测试通过），不写"优化了代码"这类空话 |
| 未决 | 必须能追究到人（"需确认 X"而不是"待完善"） |
| 踩坑 | 只写"现象 + 原因 + 处置"，不写情绪 |
| 下次第一件事 | **最重要的一项**。写不出具体动作，说明这次会话没有真正收尾 |

## 示例

```
### 002 · 2026-11-08 · M0 构建骨架

**目标**：让仓库能从零构建出一个空窗口。

**决策**
- Qt 走 vcpkg（ROADMAP Q3 定案），理由：与其它依赖同一套版本管理。

**产出**
- `CMakeLists.txt`、`CMakePresets.json`、`vcpkg.json`
- `tests/smoke/CMakeLists.txt` + `TEST(Smoke, Builds)`
- `scripts\check-docs.cmd` 通过

**未决 / 风险**
1. Skia 构建脚本尚未落地，M0 出口未满足。
2. vcpkg 的 ffmpeg 端口首次安装耗时约 25 分钟，CI 需要缓存。

**踩坑**
- vcpkg 与 VS 的 CRT 不一致导致链接报 LNK2038。原因：`VCPKG_CRT_LINKAGE` 默认 dynamic 而本地 preset 写了 /MT。处置：统一 `/MD`，写入 BUILD.md §7。

**下次第一件事**：写 `scripts/build-skia.ps1`，用 `skia_use_direct3d=true` 构建并记录实际产物名。
```

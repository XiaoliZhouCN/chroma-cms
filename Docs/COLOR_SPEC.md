# 色彩规范（规范性）

> 本文件是**唯一真值**。HLSL、SkSL、CPU 参考实现都必须与本文件逐式一致。
> 修改本文件中的任何公式或常量：**需人工确认**，并同步更新版本号与测试锚点。

- 规范版本：**v1.0（SDR）**
- 适用范围：一期 SDR 路径；HDR 章节标注 §8 为规划，未启用。

## 1. 记号与域

| 记号 | 含义 | 值域 |
|---|---|---|
| `E` | 归一化编码值（非线性，如 sRGB/709 编码） | [0, 1] |
| `L` | 线性光（相对亮度，1.0 = 参考白） | [0, ∞)，SDR 内容通常 ≤ 1 |
| `Y` | 亮度（luminance），`Y = 0.2126R + 0.7152G + 0.0722B`（线性 709） | [0, ∞) |
| 矩阵 | 行主序 3×3，作用于**列向量** | — |
| 精度 | 规范以双精度表达；着色器用 float32 | — |

规则：**所有矩阵乘法只在线性光下进行**。非线性空间里禁止矩阵乘、禁止混合、禁止缩放。

## 2. 计算顺序（固定）

```
1. 采样，得到 E'（可能为 YUV 或 RGB）
2. 若为 YUV：范围归一化 → YUV→RGB，得到 E'
3. 若源为 limited range：范围归一化
4. EOTF 解码：E' → L_src（线性，源色域）
5. 色域矩阵：L_src → L_work（线性，工作空间 = 线性 709 / D65）
6. （可选）色调映射 / 色域映射：L_work → L_disp_linear
7. 色域矩阵：L_work → L_disp（线性，显示色域）
8. OETF 编码：L_disp → E_disp
9. 量化 + 抖动 → 目标位深
```

任何实现若改变该顺序，必须在 ADR 中说明理由。

## 3. 传输函数

### 3.1 sRGB（IEC 61966-2-1）

解码（E' → L）：

```
L = E' / 12.92                          , E' <= 0.04045
L = ((E' + 0.055) / 1.055) ^ 2.4        , E' >  0.04045
```

编码（L → E'）：

```
E' = 12.92 * L                                       , L <= 0.0031308
E' = 1.055 * (L ^ (1/2.4)) - 0.055                   , L >  0.0031308
```

### 3.2 Gamma 2.2（近似显示函数）

```
L   = E' ^ 2.2
E'  = L ^ (1/2.2)
```

**注意**：gamma 2.2 不是 sRGB。两者在暗部差异可达 2%。只有在源元数据明确为"BT.1886 / gamma 2.2"时才使用。

### 3.3 BT.1886（显示参考 EOTF，可选）

```
L = (a * max(E' , 0) + b) ^ 2.4
其中 a = Lw^(1/2.4) - Lb^(1/2.4) 的归一化形式，b = 0（Lb=0 时）
```

一期按 `Lw = 1.0, Lb = 0` 退化为 `L = E' ^ 2.4`。**仅在源标注 BT.1886 时使用。**

### 3.4 PQ（ST.2084）— §8 规划

```
m1 = 2610 / 16384 = 0.1593017578125
m2 = 2523 / 32    = 78.84375
c1 = 3424 / 4096  = 0.8359375
c2 = 2413 / 128   = 18.8515625
c3 = 2392 / 128   = 18.6875

解码: Y = ( max(E'^(1/m2) - c1, 0) / (c2 - c3 * E'^(1/m2)) ) ^ (1/m1)
      亮度(cd/m²) = 10000 * Y
编码: E' = ( (c1 + c2 * Y^m1) / (1 + c3 * Y^m1) ) ^ m2
```

### 3.5 HLG（BT.2100）— §8 规划

```
a = 0.17883277, b = 0.28466892, c = 0.55991073

OETF:  E' = sqrt(3 * E)                     , E <= 1/12
       E' = a * ln(12 * E - b) + c          , E >  1/12

逆:     E  = E'^2 / 3                       , E' <= 0.5
       E  = (exp((E' - c) / a) + b) / 12    , E' >  0.5
```

HLG 还需要 OOTF（系统 gamma），取值与峰值亮度绑定；**二期实现时必须单独写 ADR**。

## 4. 色域

### 4.1 原色色度（CIE 1931 xy）

| 色域 | R | G | B | 白点 |
|---|---|---|---|---|
| BT.709 / sRGB | (0.640, 0.330) | (0.300, 0.600) | (0.150, 0.060) | D65 (0.3127, 0.3290) |
| Display P3 | (0.680, 0.320) | (0.265, 0.690) | (0.150, 0.060) | D65 (0.3127, 0.3290) |
| BT.2020 | (0.708, 0.292) | (0.170, 0.797) | (0.131, 0.046) | D65 (0.3127, 0.3290) |
| ACES AP0（仅参考） | (0.7347, 0.2653) | (0.0000, 1.0000) | (0.0001, -0.0770) | D60 |

### 4.2 矩阵来源：**推导，不硬编码**

所有 RGB↔XYZ 矩阵由 CPU 参考实现（`src/color/`，双精度）从 §4.1 的原色与白点**推导**：

```
1. 由 xy 求 XYZ:  X = x/y, Y = 1, Z = (1-x-y)/y
2. 求缩放 S = M_primaries^-1 * W，得到三原色的亮度权重
3. M = [Sr*Xr Sg*Xg Sb*Xb; ...]（列为主色向量）
```

禁止在着色器或文档中手抄矩阵数字——手抄是精度事故与两套实现不一致的头号来源。
实现方式：`scripts/gen-color-constants` 生成 `generated/color_constants.h`（CPU）与两份着色器 include。

### 4.3 色适应

不同白点之间使用 Bradford：

```
M_CAT = Bradford（9 个常量由参考实现以双精度给出）
L_dst = M_dst * inverse(M_CAT_dst) * M_CAT_src * inverse(M_src) * L_src
```

一期源与目标白点均为 D65 ⇒ CAT 为单位矩阵。仅在二期引入 ICC（D50 PCS）时启用。

## 5. YUV → RGB

### 5.1 范围归一化（必须第一步）

```
limited (8-bit):   Y' = (Y  - 16/255) * (255/219)
                   C' = (C  - 128/255) * (255/224)
full:              Y' = Y ;  C' = C - 0.5
```

10-bit 时把 `255` 换成 `1023`、`16/219/128/224` 按比例换算（16→64, 219→876, 128→512, 224→896）。

### 5.2 转换公式（由 Kr/Kb 表达，不给数字矩阵）

```
Kr, Kb 由矩阵标准决定：
  BT.601  : Kr = 0.2990, Kb = 0.1140
  BT.709  : Kr = 0.2126, Kb = 0.0722
  BT.2020 : Kr = 0.2627, Kb = 0.0593

R = Y + 2*(1 - Kr) * Cr
B = Y + 2*(1 - Kb) * Cb
G = (Y - Kr*R - Kb*B) / (1 - Kr - Kb)
```

其中 `Cb = Cb', Cr = Cr'`（已归一化到 [-0.5, 0.5]）。

**禁止默认值**：源未声明矩阵时，记录一条 WARN 并回退到 BT.709，同时该帧标记 `colorAssumed=true` 显示在状态栏。

## 6. 量化与抖动

- 输出位深 10-bit：`v = round(clamp(E_disp, 0, 1) * 1023)`
- 输出位深 8-bit：`v = round(clamp(E_disp, 0, 1) * 255)`
- 抖动：8×8 Bayer 有序抖动，幅度 **±1 LSB**，仅 Pass 2 使用：

```
v = round(E_disp * maxv + bayer8(x, y) - 0.5)
```

- 禁止对已经 8-bit 的中间结果再抖动。

## 7. 精度与容差

| 比较对象 | 指标 | 阈值 |
|---|---|---|
| HLSL vs SKSL（同帧） | 最大绝对像素差 | ≤ 1 LSB（目标位深） |
| 着色器 vs CPU 参考 | ΔE00（SDR，D65） | ≤ 0.5 |
| 矩阵 vs 独立推导 | 逐元素绝对误差 | ≤ 1e-6（双精度） |
| 白点保持 | `M_709toXYZ * (1,1,1)` 与 D65 XYZ 差 | ≤ 1e-4 |
